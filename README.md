# Awesome Threads Data [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of tools, libraries, research, and resources for working with Threads and Instagram data.

[Threads](https://threads.net) is Meta's microblogging platform, launched July 2023. This list focuses on data collection, analysis, and research use cases.

## APIs & Services

- [thredly](https://thredly.dev) - GraphQL proxy API for Threads & Instagram data with auto session management, TypeScript SDK, and Cloudflare edge deployment.
- [Threads Official API](https://developers.facebook.com/docs/threads) - Meta's official Threads API providing authenticated access to publishing, replies, and media endpoints.
- [RocketAPI](https://rocketapi.io) - Private API proxy service for Instagram and Threads data with Python and Node.js SDKs.

## SDKs & Libraries

- [threads-api-client](https://github.com/cipherc09-blip/threads-api-client) - Official TypeScript/JavaScript SDK for the thredly API with full type safety and pagination support.
- [junhoyeo/threads-api](https://github.com/junhoyeo/threads-api) - Reverse-engineered Node.js/TypeScript client for Meta's Threads with web UI (1.6k+ stars, archived).
- [dmytrostriletskyi/threads-net](https://github.com/dmytrostriletskyi/threads-net) - Unofficial reverse-engineered Python API wrapper for Threads, created for academic purposes (423 stars).
- [threadsjs/threads.js](https://github.com/threadsjs/threads.js) - Node.js library for the Threads API with support for user, post, and search operations (278 stars).
- [marclove/pythreads](https://github.com/marclove/pythreads) - Python wrapper for Meta's official Threads API, covering publishing and reply management endpoints.
- [rocketapi-io/rocketapi-python](https://github.com/rocketapi-io/rocketapi-python) - Python SDK for RocketAPI's Instagram and Threads private API proxy service.
- [iSarabjitDhiman/MetaThreads](https://github.com/iSarabjitDhiman/MetaThreads) - Python library for fetching user threads, replies, user data, and friends from the Threads app.
- [fbsamples/threads_api](https://github.com/fbsamples/threads_api) - Official Meta sample app demonstrating integration with the Threads API (276 stars).

## Research & Papers

- [The Emergence of Threads: The Birth of a New Social Network](https://arxiv.org/abs/2406.19277) - Quantitative study comparing Threads and Instagram user behavior, content preferences, and engagement patterns across 683K accounts and 10.8M posts (arXiv 2024).
- [How Does Stress Experienced on Instagram Differ from Threads?](https://www.sciencedirect.com/science/article/abs/pii/S0747563224001171) - Comparative study of social media fatigue and stress antecedents across Instagram and Threads platforms (Computers in Human Behavior, 2024).
- [Sentiment Analysis on User Reviews of Threads Applications in Indonesia](https://www.iieta.org/download/file/fid/140174) - Sentiment classification of app store reviews examining user reception of Threads post-launch (IIETA 2024).
- [InstaSynth: Opportunities and Challenges in Generating Synthetic Instagram Data](https://arxiv.org/abs/2403.15214) - Study on synthetic data generation for Instagram sponsored content detection, with annotated dataset of 804 posts (ICWSM 2024).
- [rocketapi-io/threads-private-api](https://github.com/rocketapi-io/threads-private-api) - Documented examples of Threads private API endpoints reverse-engineered for research purposes (137 stars).

## Datasets

- [Threads Dataset Analysis (Kaggle)](https://www.kaggle.com/code/anoopjohny/threads-dataset-analysis) - Exploratory analysis notebook with accompanying social media dataset covering Threads user metrics and engagement data.
- [scene-genie/instagram-dataset (Hugging Face)](https://huggingface.co/datasets/scene-genie/instagram-dataset) - Publicly available Instagram post dataset on Hugging Face for NLP and computer vision research.
- [Social Media & Misinformation Dataset 2024 (Kaggle)](https://www.kaggle.com/datasets/imaadmahmood/social-media-and-misinformation-dataset-2024) - Synthetic dataset of social media posts with engagement, sentiment, and misinformation labels for research use.

## Tools & Utilities

- [Zeeshanahmad4/Threads-Scraper](https://github.com/Zeeshanahmad4/Threads-Scraper) - Python-based Threads scraper for structured data extraction from user profiles and posts (89 stars).
- [junhoyeo/react-threads](https://github.com/junhoyeo/react-threads) - React/Next.js UI components for embedding static Threads posts in web applications (50 stars).
- [Dun-sin/Threstagram](https://github.com/Dun-sin/Threstagram) - Tool to convert Threads posts into shareable image cards in the style of Instagram posts.
- [drawrowfly/instagram-scraper](https://github.com/drawrowfly/instagram-scraper) - Node.js Instagram scraper using public APIs with no login or API keys required for post and hashtag data (798 stars).
- [meetmangukiya/instagram-scraper](https://github.com/meetmangukiya/instagram-scraper) - Python scraper for the Instagram frontend covering profiles, posts, and hashtag feeds (948 stars).
