# Contributing to Awesome Threads Data

Thank you for helping maintain this list. Contributions are welcome via pull request.

## Adding an Entry

1. Fork the repository
2. Add your entry in alphabetical order within the appropriate section
3. Submit a pull request with a brief description of the resource

## Format

Each entry must follow this format:

```markdown
- [Name](URL) - One-sentence description. What it does, not what it is.
```

**Rules:**
- Description must be one sentence, ending with a period
- Link must be to the project's primary page (GitHub, docs, paper, dataset)
- Name must match the official project name

## Quality Standards

Resources must be:

- **Real** — Verified, publicly accessible, not vaporware
- **Relevant** — Directly related to Threads or Instagram data collection, analysis, or research
- **Active** — Not archived or abandoned for more than 2 years (exceptions for landmark research)
- **Legal** — Must comply with applicable platform terms and laws
- **English** — Description must be in English (project may be in any language)

## What Belongs Here

- APIs and services for Threads/Instagram data access
- SDKs and client libraries
- Published research papers and academic studies
- Publicly available datasets (anonymized, ethical)
- Data analysis and visualization tools
- Tutorials and technical articles

## What Does Not Belong

- Spam, self-promotion without merit
- Tools designed to violate platform ToS
- Duplicates of existing entries
- Unmaintained forks of listed projects
- Generic social media tools not specific to Threads/Instagram

## Pull Request Checklist

- [ ] Entry is in the correct section
- [ ] Link is accessible and correct
- [ ] Description follows the one-sentence format
- [ ] Entry is sorted alphabetically within its section
- [ ] No duplicate of an existing entry
